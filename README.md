# speedmeter

Скрипт замера скорости интернета: по указанному адресу (например, тяжёлой картинки) последовательно
выполняет 10 запросов, дожидается полного ответа на каждый, считает среднее время запроса, объём
скачанных данных и печатает скорость в МБ/с.

## Требования

- Python 3.10+
- [uv](https://docs.astral.sh/uv/getting-started/installation/)

## Установка

```bash
git clone https://github.com/johny430/Speedmeter.git
cd Speedmeter
uv sync
```

## Запуск

```bash
uv run src/main.py <URL>
```

`<URL>` — адрес любого тяжёлого файла, например картинки размером от нескольких мегабайт.
Чем крупнее файл, тем меньше на результат влияют задержки на установку соединения.

| Опция              | По умолчанию | Описание                               |
|--------------------|--------------|----------------------------------------|
| `-n`, `--requests` | `10`         | число последовательных запросов        |
| `-t`, `--timeout`  | `30`         | сетевой таймаут в секундах             |

## Как считается

- Запросы выполняются строго последовательно: следующий начинается только после того, как тело
  предыдущего ответа получено полностью.
- Время запроса — от отправки запроса до получения последнего байта тела. Соединение
  переиспользуется (keep-alive), поэтому установка TCP/TLS попадает только в первый запрос.
- Объём — фактически полученные байты тела ответа.
- Скорость = суммарный объём / суммарное время (а не среднее скоростей отдельных запросов).
  1 МБ = 10⁶ байт; дополнительно выводится скорость в Мбит/с.
- Если запрос завершился ошибкой (HTTP 4xx/5xx, таймаут, обрыв соединения), скрипт пишет в лог
  номер запроса и причину и завершается с кодом 1. Неверные аргументы — код 2.
- Весь вывод идёт через `logging` (в stderr).

## Структура

```text
src/
├── main.py            # точка входа: запуск замера и коды выхода
├── cli.py             # разбор аргументов командной строки
├── config.py          # параметры замера с валидацией (pydantic)
├── constants.py       # константы: значения по умолчанию, HTTP, единицы, формат логов
├── enums.py           # перечисления: коды выхода
├── exceptions.py      # исключения
├── logger.py          # настройка логирования
├── meter.py           # асинхронные HTTP-запросы (httpx) и замер времени
├── models.py          # результаты: отдельный запрос и итоговый отчёт (pydantic)
├── output.py          # форматирование строк вывода
└── utils.py           # вспомогательные функции
tests/                 # pytest, общие фикстуры в conftest.py
```

## Разработка

```bash
uv run pytest
uv run ruff check . && uv run ruff format --check .
uv run mypy
```

Тесты не обращаются во внешнюю сеть: используются `httpx.MockTransport` и локальный HTTP-сервер.
